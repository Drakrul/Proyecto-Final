Actividad Extra del Proyecto Final de la Unidad 4


El programa opera con dentro de un loop WHILE que obtiene un BREAK basado en la respuesta el usuario ingresa en un mensaje de alerta al final del algoritmo confirmando si desea crear otra cotizacion o salir del programa con las entradas "Si" o "Salir". 
Se recopilan los valores que se asignan a las variables utilizadas para calcular los posibles recargos por medio de mensajes de alerta pidiendo datos que luego se convierten a valores numericos. 
Al determinar con operadores IF que determinan si algun recargo es aplicable en base a las respuestas del usuario. 
Que al comprobar los rangos o cantidad de recargos extra, multiplican el precio base por el valor del porcentaje aplicable y si es aplicable multiplican este resultado por la cantidad de veces que el recargo aplicaria, todos los posibles recargos aplicables se suman al precio base.

Tras realizar las comprobaciones y operaciones aritmeticas necesarias el programa muestra al usuario el total de los recargos y el monto total de la cotizacion. 
Luego el programa pregunta en un mensaje de alerta al usuario si desea calcular otra cotizacion o salir del programa, la entrada del usuario determina el comportamiento del loop WHILE dentro del cual esta contenido la totalidad del codigo del programa.

Se tiene que considerar que las funciones del programa deben estar contenidas dentro de la sintaxis que permite al mismo operar indefinidamente hasta que el usuario confirme que el programa cierre. 
Ademas de los posibles recargos calculados en el programa base, hay que añadir las variables, mensajes de alerta y operaciones aritmeticas necesarias para calcular los recargos por propiedades e ingresos del asegurado.

Mejoras posibles al programa seria el aspecto visual del mismo al incluir botones en el mensaje de alerta final pidiendo al usuario el confirmar "Si" o "Salir" para correr el programa de nuevo o cerrarlo, 
y tambien el poder generar una ventana con multiples etiquetas y "text boxes" permitiendo al usuario ingresar todos los datos necesarios para calcular el total de recargos y monto total de la cotizacion, 
en vez de tener que ingresar uno por uno con multiples mensajes de alerta.
